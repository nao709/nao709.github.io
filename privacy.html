プライバシーポリシー

対象：Android アプリ「AWS 学習管理」（以下「本アプリ」）

取得する情報

本アプリは、利用者が端末で入力・記録した学習データ（問題の回答記録、進捗、Lab の完了状況、演習時間など）を扱います。

Google アカウントの利用

本アプリは、利用者の複数の端末で学習データを同期するために、Google ドライブのアプリ専用領域（appDataFolder）へのアクセス権限（https://www.googleapis.com/auth/drive.appdata）だけを要求します。この権限で読み書きできるのは本アプリが作ったデータだけで、利用者のドライブ上のほかのファイルには一切アクセスしません。

データの保存場所と第三者への提供

学習データは、利用者の端末と、利用者自身の Google ドライブのアプリ専用領域にだけ保存されます。開発者のサーバーへは送信せず、開発者が学習データを収集・閲覧することはありません。第三者への提供、広告、アクセス解析も行いません。

データの削除

本アプリをアンインストールすると端末上のデータは削除されます。Google ドライブ上のデータは、Google ドライブの設定「アプリの管理」から本アプリのデータを削除できます。

Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から取得した情報の利用は、Limited Use の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。
